This phase is designed to help participants ensure that their Docker-based submission behaves correctly under the remote evaluation setup. It provides a sanity check before submitting to the full evaluation phase.

Specifically, it consists of 10 RGB-D episodes selected from the Social-HM3d dataset. The goal is to verify that your submission produces consistent results between local inference and remote evaluation.

📂 Important: All evaluation data (Minival, Phase I, Phase II) is mapped to /app/Falcon/data/datasets/pointnav/social-hm3d/minival inside the container. If your code works with Minival paths, it will work for all phases.

We strongly encourage participants to use this phase to:

  • Verify submission format (directory structure, config files, result file) meets specifications
  • Test Docker container functionality and GPU inference (if applicable)
  • Debug environment issues (dependencies, file paths, libraries)
  • Ensure the evaluation script can read your output/result.json file

🚀 Fast-Track Evaluation: Minival submissions are processed with priority scheduling for rapid debugging. Maximum 3 submissions per day allowed.

Note: Submissions to this phase do not affect the final ranking, but the leaderboard shows the latest result from each team.
